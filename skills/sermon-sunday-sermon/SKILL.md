# 설교문 · 목회 글 작성

개혁주의 입장에서 장년 회중을 대상으로 쉽고 깊고 은혜롭게 작성한다.
성경은 **개역개정** 번역을 사용한다.

---

## 핵심 원칙 (모든 유형 공통)

1. **개혁주의 신학** — 하나님의 주권·은혜·그리스도 중심·성령의 역사
2. **개역개정 성경** — 다른 번역 사용 금지
3. **쉽고 은혜로운 설교체** — 단문 위주, "~입니다/~하십시오/여러분" 직접 호칭
4. **원어 텍스트 금지** — 히브리어·헬라어 단어는 설교체 한국어로만 풀어서 표현
5. **이단 사상 배격** — 신천지 등 이단 교리 절대 불포함
6. **신선한 예화** — 뻔한 예화 금지, 최신 시사·실화 활용 가능
7. **거짓 정보 금지** — 확인되지 않은 인물·연구·통계 절대 사용 금지; 출처 불명확 시 "여러 연구에서 확인된 사실" 등으로 표현
8. **해돈 로빈슨 빅 아이디어** — 서론에 "주어 + 술부" 한 문장으로 명확히 선언; 결론에서 재수렴
9. **축원 마무리** — 결론 맨 마지막 문장: "우리 주 예수 그리스도의 이름으로 축원합니다"
10. **본문에서 나온 웃음** (주일오전예배) — 본문이 허락하는 곳에서 회중이 크게 웃고 곧바로 "아, 그래서 그렇구나" 하고 깨닫는 순간을 2회 안팎 설계한다. 아래 「웃음 설계 지침」을 따른다.

---

## 실행 순서

### 1단계: 설교 유형 파악

사용자 입력에서 아래 유형 중 하나를 결정한다. 불명확하면 확인한다.

| 유형 | 구조 | 분량 |
|------|------|------|
| 주일오전예배 | 서론 → 1·2·3대지 → 결론 → 마무리기도 | A4 8-10장 |
| 새벽기도회 | 서론 → 1·2대지 → 결론 → 기도 | A4 1-2장 |
| 1포인트 | 서론 → 1포인트 전개 → 결론 | A4 2-3장 |
| 월삭기도회 | 서론 → 1·2대지 → 결론 + 이달 헌신 촉구 | A4 2-3장 |
| 목회컬럼 | 제목 → 도입 → 본론 → 마무리 | 지정 글자 수 |
| 부흥회 | 서론(감동적 오프닝) → 1·2·3대지 → 결단 촉구 결론 | A4 8-10장 |
| 헌신예배 | 서론 → 1·2·3대지 → 헌신 촉구 결론 | A4 6-8장 |
| 주일설교요약 | 제목·본문·빅아이디어·대지 요약 | 지정 형식 |

### 2단계: 중복 예화 점검

```bash
ls outputs/*.docx outputs/*.md 2>/dev/null
```

> 출력 폴더(`outputs/`)는 작업 환경에 맞게 바꿔 사용한다. Cowork 환경이라면 세션의 `mnt/outputs/` 폴더를 사용한다.

최근 파일 1-2개를 읽어 이미 사용된 예화 인물·사건을 파악한다. 같은 예화를 반복하지 않는다.

### 3단계: 설교 내용 작성

아래 유형별 구조에 따라 작성한다.

### 4단계: docx 파일 생성

`scripts/create_sermon_docx.js`의 helper 함수를 참고해 Node.js로 생성한다.

```bash
node -e "require('docx')" 2>/dev/null || npm install docx
```

출력 경로: `outputs/YYYY-MM-DD_제목_본문.docx`

## 유형별 구조

### 주일오전예배 (3대지 강해)

#### 서론 (600자)
- 현재 사회 이슈 또는 보편적 삶의 질문으로 시작 (은혜롭게)
- 본문 소개 및 자연스러운 연결
- **빅 아이디어 선언** (quoteBlock): "주어 + 술부" 완전한 한 문장

#### 1대지 · 2대지 · 3대지 (각 동일 구조)
- **대표 구절** (subLabel + quoteBlock)
- **본문 해설** (700자) — 역사적·문화적·문맥적 배경, 핵심 개념 2-3개 설교체 해설
- **성경 예화** (600자) — 본문 외 인물·사건, 중복 금지
- **일반 예화** (500자) — 시사·교회사·실화, 거짓 정보 금지
- **적용** (500자) — 성도의 구체적 삶에 적용
- **대지 연결 문장** (connector)

#### 웃음 설계 지침 (주일오전예배 필수 점검)

**원칙: 웃음은 본문이 요구할 때만 나온다.** 목표는 2회 안팎이지만 횟수를 억지로 채우지 않는다. 본문이 무거운 주일(고난·죄·심판·성찬 주일 등)에는 1회로 줄이거나 넣지 않는다.

**목적:** 분위기를 띄우는 데 있지 않다. 웃음이 본문의 진리를 더 선명하게 드러내야 한다. 회중이 웃고 난 다음 "아, 그래서 그렇구나" 하고 깨달아야 한다.

**웃음의 출처 (우선순위 순)**
1. 본문 속 장면: 인간의 어리석음·역설·반전이 드러나는 곳 (예: 박넝쿨 하나에 "죽는 것이 낫다"는 요나, 요단강에서 투덜대는 나아만, 나귀에게 책망받는 발람, "주님은 절대 그럴 수 없습니다" 하는 베드로)
2. 본문과 같은 구조를 가진 일상 장면이나 설교자 자신의 실수담 (실화만 사용하고, 꾸민 이야기를 실화처럼 말하지 않는다)
3. 본문의 진리와 정확히 맞닿는 짧은 기독교 유머 (본문과 연결되지 않으면 사용 금지)

**3단계 흐름 (나단 방식: "당신이 그 사람이라")**
1. **장면**: 인물의 모습을 생생하고 유머러스하게 묘사해 회중이 웃게 한다.
2. **멈춤과 전환**: 웃음이 가라앉을 때 시선을 회중 자신에게 돌린다.
   (예: "여러분, 웃으셨지요? 그런데 이 요나가 누구입니까? 지난주 주차 자리 하나에 성냈던 저와 여러분입니다.")
3. **진리 선언**: 그 장면이 드러내는 본문의 진리를 대지의 메시지와 연결해 한 문장으로 선언한다.
- 웃음이 "저 사람 참 우습다"에서 끝나면 실패다. 반드시 "저 모습이 바로 나구나"로 넘어가야 한다.

**배치**
- 서론, 1대지, 2대지의 **본문 해설** 또는 **성경 예화/일반 예화** 안에 자연스럽게 녹인다. 별도 소제목은 만들지 않는다.
- 3대지 후반부, 결론, 마무리 기도에는 넣지 않는다. 설교의 무게와 결단의 흐름을 지킨다.

**금지**
- 하나님, 그리스도, 십자가, 성령, 성례를 웃음의 소재로 삼는 것
- 특정 교인·직분자·성별·세대·지역·장애·타 교단·타 종교를 조롱하는 것
- 본문과 무관한 인터넷 유머나 아재개그를 끼워 넣는 것
- 출처가 불분명한 이야기를 실화처럼 포장하는 것 (핵심 원칙 7 적용)
- 웃음 뒤에 전환 없이 곧바로 다음 내용으로 넘어가는 것

**보고**: 설교 완성 후 사용자에게 드리는 요약에 웃음 포인트마다 **위치(대지/항목) · 장면 요약 · 전환 문장**을 명시한다. 본문상 웃음을 넣지 않았다면 그 이유를 한 줄로 밝힌다.

#### 결론 (500자)
- 3대지 요약
- **빅 아이디어 재수렴** (quoteBlock으로 강조)
- 은혜와 결단 촉구
- 마지막 문장: "우리 주 예수 그리스도의 이름으로 축원합니다."

#### 마무리 기도 (300자)

---

### 새벽기도회
짧고 은혜롭게. 서론(200자) → 1대지(본문해설+적용) → 2대지(본문해설+적용) → 결론(빅 아이디어 + 축원) → 기도(200자)

### 1포인트 설교
한 가지 핵심 메시지 집중. 서론(빅 아이디어) → 본문해설 → 성경예화 → 일반예화 → 적용 → 결론(빅 아이디어 재수렴 + 축원)

### 월삭기도회
주일오전 2대지 구조. 결론에서 "이달 한 달 ○○의 삶을 살기로 결단하십시오" 형식으로 월별 헌신 촉구. 빅 아이디어 + 축원.

### 목회 컬럼
- 지정 글자 수 엄수 (공백 포함)
- 쉽고 따뜻한 산문체 (설교체 아님)
- 시사 예화 → 성경 통찰 → 삶의 적용 흐름
- 거짓 통계·연구 인용 절대 금지

### 부흥회 설교
감동적 오프닝. 3대지 구조, 각 대지 말미에 결단 촉구 문장 추가. 강력한 초청과 결단으로 결론. 빅 아이디어 + 축원.

### 헌신예배 설교
헌신 대상(교사·청년·직분자 등)을 서론에서 직접 호칭. 소명·헌신·섬김 신학적 뒷받침. 3대지. 빅 아이디어 + 축원.

### 주일설교요약
사용자 제공 원고·정보 기반 작성.
- **3대지 요약**: 빅 아이디어 + 1·2·3대지 한 줄씩 + 결론 한 줄
- **주보용**: 200-300자 완성 단락
- **SNS용**: 300자 이내, 해시태그 포함

## docx 스타일 가이드

`scripts/create_sermon_docx.js`의 helper 함수:

| 함수 | 용도 |
|------|------|
| `heading1(text)` | 서론/대지/결론/기도 제목 (파란색 하단 테두리) |
| `heading2(text)` | 본문해설/성경예화/일반예화/적용 소제목 |
| `subLabel(text)` | 대표 구절 표시 (빨간색 볼드) |
| `quoteBlock(text)` | 대표 구절·빅 아이디어 인용 (빨간 왼쪽 테두리, 이탤릭) |
| `connector(text)` | 대지 간 연결 문장 (우측 정렬, 파란색) |
| `p(text)` | 일반 단락 |
| `empty()` | 빈 줄 |

폰트: 맑은 고딕, 기본 12pt, A4 용지
