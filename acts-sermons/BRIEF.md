# 사도행전 주제별 연속설교 70편 — 집필 지침 (작성자용)

설교자: 개혁주의 목사(장년 회중, 주일오전예배). 시리즈 목록은 `plan.tsv`(번호·본문·제목·부·날짜, 탭 구분).

## 산출물
각 설교 하나당 `json/NN.json` 파일 하나(NN = 두 자리 번호, 예: `json/07.json`). UTF-8, 유효한 JSON.
작성 후 반드시 `cd /home/user/cys-claude-sermon-skills/acts-sermons && NODE_PATH=$(npm root -g) node build.js json/NN.json` 로 docx 변환이 성공하는지 확인한다.

```json
{

  "date": "2026-11-29",
  "part": "예루살렘",
  "title": "plan.tsv의 제목 그대로",
  "passage": "사도행전 2:5-13",
  "passageText": "본문 전체(개역개정). 본문이 10절 넘게 길면 핵심 구절 3-6절만 싣고 '…'로 생략 표시",

  "intro": ["단락", "..."],
  "points": [

      "heading": "1대지 – 대지 문장(선언형)",
```

## 분량 (공백 포함, 한국어 글자 수 — 반드시 지킬 것)
- 서론 약 600자 (빅 아이디어 선언 문장으로 마무리; bigIdea 필드는 서론 뒤에 별도 인용 블록으로 출력됨)
- 각 대지: 본문 해설 약 700자 / 성경 예화 약 600자 / 일반 예화 약 500자 / 적용 약 500자
- 결론 약 500자, 마무리 기도 약 300자
- 설교 한 편 합계 약 8,000자 이상 (A4 8-10장). 짧게 쓰지 말 것.

## 신학·문체 원칙
1. 개혁주의: 하나님의 주권, 오직 은혜, 그리스도 중심, 성령의 역사, 말씀의 충족성. 사도행전을 '성령을 통해 계속되는 승천하신 그리스도의 사역'(구속사적 관점)으로 읽고, 서술적 본문을 무리하게 규범화하지 않는다(예: 방언·표적의 오늘날 반복 요구, 제비뽑기 권장 등 금지). 은사주의·번영신학·율법주의 경계.
2. 성경은 개역개정만 사용. 인용 문구는 개역개정 원문에 충실하게. 확신이 없으면 직접 인용 대신 장절을 밝혀 풀어서 말한다.
3. 쉬운 설교체: 단문 위주, "~입니다 / ~하십시오 / 사랑하는 성도 여러분" 직접 호칭. 장년이 귀로 듣고 바로 이해할 수 있게.
4. **원어 금지**: 헬라어·히브리어 글자나 음역(예: '파루시아', 'λόγος', '에클레시아') 쓰지 말고 "원어의 뜻은 ~입니다"처럼 한국어로만 풀어 설명.
5. 이단 사상(신천지 등) 절대 불포함.
6. **거짓 정보 금지**: 실존 인물·사건·연구·통계는 널리 검증된 사실만. 지어낸 대화, 출처 없는 수치, 확인 안 된 일화, 가짜 인용문 금지. 불확실하면 세부를 빼고 일반화하여 말하거나("여러 연구에서 확인된 사실처럼") 다른 예화를 쓴다. 날짜·숫자는 확실할 때만.
7. 신선한 예화: 뻔한 예화 지양. 일반 예화는 교회사·선교사·실화·역사·과학·시사(2020년대 포함) 등.
8. 해돈 로빈슨 빅 아이디어: 서론에서 선언, 결론에서 재수렴(conclusion.bigIdea).
9. 결론 마지막 문장은 정확히 "우리 주 예수 그리스도의 이름으로 축원합니다."로 끝난다(after 배열의 마지막 단락 끝).
10. 각 설교의 서론은 서로 다른 방식으로 시작(시사, 질문, 장면 묘사, 일상 경험 등) — 매번 같은 패턴 금지.

## 예화 중복 방지 (70편 전체에서 같은 예화 반복 금지)
- 각 작성자는 아래 배정된 **일반 예화 영역**을 우선 사용한다. 다른 영역의 대표 인물은 쓰지 않는다(그 영역 담당자가 씀).
- 금지(이미 사용됨): 기드온 300용사, 다니엘 사자굴, 스펄전의 우울증/강단 일화, 존 번연 천로역정 감옥, 손자병법, C.S. 루이스 스크루테이프.
- 성경 예화도 한 작성자 안에서 같은 인물·사건 반복 금지. 사도행전 본문 자체 사건은 '성경 예화'로 쓰지 말고, 본문 외 구약·복음서·서신 인물/사건을 쓴다.
- 담당 범위 안에서 같은 성경 인물을 두 번 쓰지 않는다. 다른 작성자와 겹칠 가능성이 큰 '단골' 예화(요셉의 용서, 모세의 떨기나무, 다윗과 골리앗, 엘리야의 갈멜산, 탕자 비유, 삭개오)는 가급적 피하고 덜 알려진 인물(예: 므비보셋, 에벳멜렉, 요시야, 미가야, 오네시보로, 에바브로디도, 룻, 하박국, 갈렙, 한나, 나아만의 여종 등)도 활용한다.
