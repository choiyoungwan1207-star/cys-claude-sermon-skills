# 예화 중복 정리 지침 (교체 작업자용)

70편 전체에서 성경 예화가 여러 편에 반복되었다. 아래 "교체 대상"의 성경 예화를 지정된 **예비 목록(pool)** 안의 인물·사건으로 바꾼다.

규칙
1. 대상 설교의 json을 읽고, 교체 대상 예화가 들어 있는 대지의 `bibleIllustration` 단락들을 새 예화로 다시 쓴다(약 600자, 기존과 비슷한 분량, 같은 대지의 메시지에 정확히 맞게, 마지막에 대지 주제로 자연스럽게 연결).
2. 예비 목록에서 그 대지에 가장 잘 맞는 것을 고른다. 한 항목은 한 번만 사용(내 목록 안에서도 중복 금지). 예비 목록 밖의 인물은 쓰지 말 것(다른 작업자 목록과 충돌).
3. 교체된 옛 예화가 서론·해설·적용·결론·기도 등 다른 곳에서 언급되면 그 언급도 자연스럽게 고친다(grep으로 확인).
4. `illustrations` 필드의 해당 항목을 새 예화로 바꾼다.
5. BRIEF.md 원칙 유지: 개역개정, 원어 금지, 쉬운 설교체, 거짓 정보 금지, 개혁주의. 성경 인용은 개역개정에 충실하게, 불확실하면 풀어서.
6. 저장 후 `cd /home/user/cys-claude-sermon-skills/acts-sermons && NODE_PATH=$(npm root -g) node build.js json/NN.json` 로 재생성. JSON 유효성 확인.
7. 지정된 번호 외 파일은 건드리지 말고, git 커밋은 하지 말 것.
