# 독립 리뷰 지침 (검토자용)

당신은 이 원고를 쓰지 않은 독립 검토자입니다. 설교자: 개혁주의 목사, 장년 회중 주일오전예배. 먼저 BRIEF.md를 읽어 원래 기준을 파악하십시오.
담당 번호의 `json/NN.json`을 한 편씩 전부 읽고 아래 4가지를 검토한 뒤, **문제는 json에서 직접 고치고** 기록을 남깁니다.

## 검토 기준
1. **개역개정 인용 정확성**: passageText, keyVerse, 본문 중 따옴표 직접 인용. 개역개정 문구와 다르면 바로잡는다. 가능하면 WebSearch/WebFetch로 개역개정 본문을 확인한다(네트워크가 안 되면 지식으로 판단). 확신할 수 없는 직접 인용은 따옴표를 빼고 장절을 밝혀 풀어쓴 문장으로 바꾼다. 장절 표기 오류도 고친다. 개역한글 표현이 섞였으면 개역개정으로.
2. **예화·사실관계**: 인물·연도·장소·숫자·인용문이 역사적 사실과 맞는지. 틀리면 고치고, 검증이 어려운 세부(정확한 발언, 수치)는 삭제하거나 "전해집니다" 수준으로 완화. 지어낸 대화·가짜 인용문은 제거. 성경 예화도 성경 내용과 맞는지(인물 혼동, 사건 순서 등).
3. **신학**: 개혁주의 정통성 — 하나님의 주권과 은혜, 이신칭의, 그리스도 중심, 성령론(두 번째 축복론·은사 규범화 배격), 사도행전 서술 본문의 무리한 규범화 금지, 번영신학·율법주의·도덕주의(그리스도 없는 '본받자'만의 설교) 경계, 구원론 오류(행위구원 뉘앙스, 보편구원 뉘앙스) 없음. 문제 표현은 바로잡는다.
4. **설교 품질**: 빅 아이디어가 본문의 중심 사상과 일치하는지, 3대지가 본문에서 나오는지, 적용이 구체적인지, 원어(헬라어·히브리어 글자·음역) 없음, 마지막 문장 "우리 주 예수 그리스도의 이름으로 축원합니다." 유지. 사소한 문장 다듬기는 하지 말고 의미 있는 문제만 고친다.

## 고칠 때 주의
- 분량을 크게 줄이지 말 것(줄였다면 같은 대지에서 보충). 수정 후 각 편 본문 글자 수(intro, bigIdea, 대지 4항목, conclusion, prayer 합)가 8,000자 이상인지 확인.
- 예화 인물을 새로 바꾸지 말 것(70편 전체 중복 관리 중). 사실이 틀린 예화를 도저히 살릴 수 없을 때만 같은 대지 안에서 일반화된 서술로 대체하고 기록에 명시.
- illustrations 필드도 일관되게 유지.
- 저장 후 `cd /home/user/cys-claude-sermon-skills/acts-sermons && NODE_PATH=$(npm root -g) node build.js json/NN.json` 로 재생성, JSON 유효성 확인. 커밋 금지. 담당 외 파일 수정 금지.

## 기록
`review/NN-MM.md`(담당 범위)에 편별로 작성:
```
## NN 제목
- [인용] 행 2:38 '…' → '…' (개역개정 대조)
- [사실] … 수정/완화
- [신학] …
- [품질] …
- 확인 불가(목사님 확인 권장): …
(문제 없으면 "문제 없음")
```
마지막에 범위 전체 요약(수정 건수 분류별, 목사님께 꼭 확인을 권할 항목).
