# 독립 리뷰 기록 21~30

검토 방법: 개역개정 대조는 네트워크 차단(성서공회·holybible 접속 불가)으로 지식에 근거해 판단함. 수정 후 전 편 build.js 변환 성공, JSON 유효, 본문 글자 수 8,000자 이상 확인(21: 8,246 / 22: 8,661 / 23: 8,686 / 24: 8,656 / 25: 8,495 / 26: 8,121 / 27: 8,127 / 28: 8,294 / 29: 8,899 / 30: 8,539). 마지막 문장 "우리 주 예수 그리스도의 이름으로 축원합니다." 전 편 유지.

## 21 천사의 얼굴을 한 사람
- [인용] 왕상 18:3 '오바댜는 여호와를 크게 경외하는 자라' → '오바댜는 여호와를 지극히 경외하는 자라' (개역개정 대조). 같은 표현을 쓴 성경 예화 마무리와 결론 요약도 '지극히 경외하며'로 맞춤.
- [사실] 리처드 백스터(1615년 11월생)는 1685년 재판 당시 69세 → '일흔 살이 넘은 노인' → '일흔을 바라보는 노인'.
- 확인 불가(목사님 확인 권장): 존 오웬이 임종 직전 윌리엄 페인에게 한 말은 이미 '전해지는 바에 따르면'으로 완화되어 있어 그대로 둠.

## 22 성전보다 크신 하나님
- [인용] 행 6:13 서론 인용 '이 사람이 거룩한 곳과 율법을 거슬러 말한다' → '이 사람이 이 거룩한 곳과 율법을 거슬러 말하기를 마지아니하는도다'(행 6:13).
- [인용] 행 7:2 어순을 바꾼 인용 → 개역개정 원문 순서대로 바로잡음.
- [인용] 행 7:5 '발 붙일 만큼도' → '발 붙일 만한 땅도'.
- [인용] 행 7:33 '네가 서 있는 곳은 거룩한 땅이니 신을 벗으라' → '네 발의 신을 벗으라 네가 서 있는 곳은 거룩한 땅이니라'.
- [인용] 행 7:27 '누가 너를 우리 위에 관리와 재판장으로 세웠느냐' → '누가 너를 관리와 재판장으로 우리 위에 세웠느냐'.
- [인용] 행 7:35 의역 인용 '…속량하는 자로 보내셨다' → '…관리와 속량하는 자로서 보내셨으니'.
- [인용] 겔 11:16 '그들이 이른 나라들에서'(개역한글식) → '그들이 도달한 나라들에서'.
- 그 밖에 신학·품질 문제 없음.

## 23 하나님 우편에 서신 예수
- [인용] 시 110:1 '내 우편에 앉아 있으라' → '너는 내 오른쪽에 앉아 있으라'(개역개정 시편 표기).
- [인용] 히 10:12 '하나님 우편에 앉으셨다' → '하나님 우편에 앉으사'.
- [인용] 눅 22:69 '이 후에는 인자가 권능의 우편에 앉아 있으리라' → '그러나 이제부터는 인자가 하나님의 권능의 우편에 앉아 있으리라'.
- 확인 불가(목사님 확인 권장): 문준경 전도사 일화 중 '세상의 법정은 그녀를 반동이라 정죄했습니다'는 수사적 표현임. 순교 연월(1950년 10월)과 장소(증도)는 맞음.

## 24 흩어진 사람들이 두루 다니며
- [사실] 메러디스 빅토리호가 '원래 실었던 무기를 내리고' 피난민을 태웠다는 서술은 널리 알려졌으나 검증되지 않은 대중적 설명임(실제로는 항공유 일부가 실린 채 출항했다는 기록이 있음) → '피난민을 태우기로 했습니다'로 완화. 약 1만 4천 명, 성탄절 무렵 거제 도착은 유지.
- 그 밖에 문제 없음.

## 25 돈으로 살 수 없는 하나님의 선물
- [인용] 눅 19:4 '뽕나무'(개역한글) → '돌무화과나무'(개역개정).
- [인용] 창 14:22-23 어순을 바꾸고 '들메끈'(개역한글)을 쓴 인용 → 개역개정 원문 '천지의 주재이시요 … 실 한 오라기나 신발 끈 한 가닥도 내가 가지지 아니하리라'로 교체.
- [인용] 삼상 15:15 사울의 변명을 따옴표로 의역한 부분 → 따옴표를 빼고 장절을 밝힌 간접 서술로 바꿈.
- 확인 불가(목사님 확인 권장): 길선주 장로의 1907년 공개 고백(작고한 친구 유산 일부를 가로챔)은 통상 전해지는 내용과 일치함. 액수 같은 세부는 쓰지 않았음.

## 26 읽는 것을 깨닫느냐
- [인용] 눅 24:27 인용 어미 '자세히 설명하셨습니다' → '자세히 설명하시니라'.
- [품질] 창 24장 예화의 지명 '메소포타미아' → 개역개정 표기 '메소보다미아'(22편과 통일).
- 그 밖에 문제 없음(1913년 산둥 선교사 3인 파송, 이수정 마가복음 1885년 요코하마 간행은 사실과 맞음).

## 27 주여 누구시니이까
- [인용] 적용의 '주여 무엇을 하리이까' → '주님 무엇을 하리이까'(행 22:10)로 바꾸고, 9장이 아니라 바울이 훗날 회고한 22장의 말임을 밝힘.
- 확인 불가(목사님 확인 권장): 이기풍이 마포삼열 선교사에게 돌을 던져 턱을 다치게 했다는 일화는 '전해집니다'로 처리되어 있음(널리 알려진 전승).

## 28 택한 나의 그릇
- 문제 없음. (행 22:12, 렘 1:5-6, 갈 1:15, 고후 4:7, 요 6:9, 빌 2:25·30 인용 모두 개역개정과 일치. 태안 2007, 한경직 1992 템플턴상과 신사참배 고백, 장기려 복음병원 1951과 청십자 1968 모두 사실과 맞음.)
- 확인 불가(목사님 확인 권장): 장기려 박사가 '평생 병원 옥상의 작은 방에서 살았다'는 '전해집니다'로 완화되어 있음.

## 29 교회가 평안하여 든든히 서 가고
- [인용] 행 9:15 '나의 택한 그릇' → '택한 나의 그릇'.
- 그 밖에 문제 없음(저드슨과 제이콥 임스 일화, 풀러의 '밧줄' 회고, 레드우드 뿌리 설명은 사실과 맞음).

## 30 일어나라, 다비다야
- [인용] 행 3:12 '어찌하여 우리를 주목하느냐' → '우리 개인의 권능과 경건으로 이 사람을 걷게 한 것처럼 왜 우리를 주목하느냐'(행 3:12).
- [인용·품질] '성전 미문의 앉은뱅이'(개역한글 표현이자 비하어) → '성전 미문에 앉아 있던 나면서 못 걷게 된 사람'(행 3:2 개역개정).
- [사실] 아이다 스커더 사역의 결과를 '벨로르의 여성 의과대학' → '벨로르의 기독교 의과대학'. 여자 의학교로 시작했으나 오늘날 기관은 남녀공학인 기독교 의과대학(CMC)이므로 바로잡음.
- 그 밖에 신학 문제 없음(표적의 규범화를 경계하는 문장이 이미 있음).

## 범위 전체 요약 (21~30)
- [인용] 21건: 21편 1, 22편 7, 23편 3, 25편 3, 26편 1, 27편 1, 29편 1, 30편 2(미문 표현 포함)
- [사실] 3건: 21편 백스터 나이, 24편 메러디스 빅토리호 '무기 하역', 30편 스커더 의과대학 명칭
- [신학] 0건. 10편 모두 그리스도 중심이고, 표적·안수·성령 받음을 오늘날의 규범으로 삼지 않도록 경계하는 문장이 이미 들어 있음.
- [품질] 1건: 26편 지명 표기 통일. 빅 아이디어와 3대지는 모두 본문에서 나왔고, 원어 글자나 음역은 없음.

### 목사님께 꼭 확인을 권할 항목
1. **같은 성경 인물의 반복(22~28 작성자 범위)**: 예레미야가 24편(렘 29 편지), 27편(렘 18 토기장이), 28편(렘 1 소명)에서 세 번 쓰였습니다. 나아만도 22편(눅 4장 안에서 언급)과 24편(나아만의 여종)에 나옵니다. 지침상 예화 인물은 바꾸지 않았으니, 중복을 정리할지 판단해 주십시오.
2. **단골 예화 사용**: 25편 3대지에 BRIEF가 '가급적 피하라'고 한 삭개오(눅 19장)가 쓰였습니다.
3. **네트워크 대조 불가**: 개역개정 원문을 온라인으로 대조하지 못했습니다. 특히 겔 11:16 '도달한 나라들', 행 22:10 '주님 무엇을 하리이까', 시 110:1 '오른쪽' 세 곳은 인쇄본으로 한 번 더 확인해 주십시오.
4. 위에 '확인 불가'로 표시한 전승성 일화(이기풍의 돌팔매, 오웬의 임종 발언, 장기려의 옥탑방, 문준경 관련 수사)는 이미 '전해집니다' 수준으로 처리되어 있습니다.
