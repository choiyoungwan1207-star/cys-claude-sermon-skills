# 독립 리뷰 기록: 01~10편

검토 방법: 각 편 json 전체를 읽고 REVIEW.md 기준 4가지(인용·사실·신학·품질)를 확인했습니다. 대한성서공회 등 외부 성경 사이트는 네트워크 정책으로 접속되지 않아, 개역개정 대조는 지식에 근거했습니다. 확신이 없는 직접 인용은 따옴표를 빼고 장절을 밝혀 풀어 썼습니다. 수정 후 10편 모두 build.js 변환 성공, JSON 유효, 본문 글자 수 8,000자 이상(8,182~9,409자)을 확인했습니다.

## 01 계속되는 예수님의 일
문제 없음
(passageText·keyVerse와 수 1:2·5, 슥 4:6-7, 요 20:25-29 인용 확인. 보이저 1호(1977 발사, 2012 성간 진입), 이레니우스의 플로리누스 서신, 아타나시우스의 다섯 번 유배는 사실과 일치)

## 02 성령의 권능과 증인의 사명
- [사실] 2대지 해설: "베드로는 여종 앞에서 예수님을 세 번 부인" → "대제사장의 집 뜰에서 여종과 사람들 앞에서 세 번 부인" (눅 22:56-60에 따르면 세 번 모두 여종 앞은 아님)
- 확인 불가(목사님 확인 권장): 행 1:7은 개역개정 "때와 시기는"으로 판단해 그대로 두었습니다(개역한글은 "때와 기한은").

## 03 승천하신 주님, 다시 오실 주님
- [인용] 서론의 사도신경 인용 "하늘에 오르시어 … 저리로서 … 오시리라"는 구판과 새 번역이 섞여 있음 → 구판 그대로 "하늘에 오르사 전능하신 하나님 우편에 앉아 계시다가 저리로서 산 자와 죽은 자를 심판하러 오시리라"
- [사실] 1대지 일반 예화: "천 년 가까이 무너진 적이 없던 도시 로마" → "팔백 년 동안 외적에게 함락된 적이 없던 도시 로마" (주전 390년경 갈리아족의 로마 약탈 이후 410년까지 약 800년)

## 04 마음을 같이하여 기도에 힘쓰는 교회
- [인용] 행 1:4 "예루살렘을 떠나지 말고 아버지께서 약속하신 것을 기다리라"(중간 생략됨) → "예루살렘을 떠나지 말고 내게서 들은 바 아버지께서 약속하신 것을 기다리라"

## 05 제비를 뽑으신 하나님의 주권
- [인용] passageText 행 1:15 "모든 형제 약 백이십 명이나 모였더라" → "모인 무리의 수가 약 백이십 명이나 되더라" (개역개정)
- [인용] 1대지 해설에서 행 1:20의 시편 인용 "그의 거처를 황폐하게 하시며 거기 거하는 자가 없게 하소서", "그의 직분을 타인이 취하게 하소서"는 개역한글 표현과 섞였을 가능성이 있음 → 따옴표를 빼고 시 69:25, 109:8을 밝혀 풀어 씀
- [신학] 제비뽑기를 규범화하지 않고, 하나님의 주권과 유다의 책임, 사도직이 단회적이라는 점을 바르게 다루고 있어 수정 없음
- 확인 불가(목사님 확인 권장): 행 1:15 개역개정 문구는 지식에 근거해 고쳤습니다. 성경책으로 한 번 확인해 주십시오.

## 06 오순절, 성령이 임하신 날
문제 없음
(오순절은 단회적 사건이고 모든 신자가 성령을 받는다는 점, 언어 표적을 규범화하지 않는 점, 날마다 충만함을 구하라는 엡 5:18 적용 모두 개혁주의 성령론에 맞음. 바실리우스와 381년 신경, 유스티누스의 회심 회고, 제트기류 내용은 사실과 일치)

## 07 각 사람의 난 곳 방언으로 듣는 복음
- [사실] 2대지 일반 예화: "고트족 출신 가정에서 자란 울필라스" → "고트족 가운데서 태어나 자란 울필라스" (그의 조상은 고트족에게 잡혀간 갑바도기아 출신으로 전해짐)
- 확인 불가(목사님 확인 권장): 울필라스는 성경 번역자이지만 신학적으로는 아리우스파(정확히는 호모이안) 계열이었습니다. 설교는 번역 업적만 다루므로 그대로 두었습니다. 다만 개혁주의 강단에서 긍정적 모범으로 드는 것이 괜찮은지 판단해 주십시오.

## 08 주와 그리스도가 되게 하셨느니라
- [사실] 서론: "불과 두 달 전, 여종 하나 앞에서 … 세 번이나 모른다고" → "불과 오십여 일 전, 대제사장의 집 뜰에서 … 세 번이나 모른다고" (유월절에서 오순절까지 약 50일, 부인 장면도 02편과 같은 문제)
- [인용] 3대지 해설: 행 2:34-35 직접 인용 "… 너는 내 우편에 앉아 있으라"는 개역개정 행 2:35("앉았으라")와 시 110:1("앉아 있으라")의 문구가 섞였을 가능성이 있음 → 따옴표를 빼고 장절을 밝혀 풀어 씀
- 확인 불가(목사님 확인 권장): 08·09·10편이 모두 칼빈 예화를 씁니다(비석 없는 무덤, 갑작스러운 회심, 제네바 시편 찬송가). 일화가 서로 달라 중복 금지 위반은 아니라고 보고 그대로 두었습니다. 연속 3주에 같은 인물이 나오는 것이 괜찮은지 판단해 주십시오.
