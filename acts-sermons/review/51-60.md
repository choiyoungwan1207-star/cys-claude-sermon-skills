# 독립 리뷰 기록: 51~60편

검토 기준: REVIEW.md 4개 항목(개역개정 인용 / 예화·사실관계 / 신학 / 설교 품질). 웹 검색은 일부만 가능했고(디모데후서 1:5, 열왕기하 23:25 대조), 나머지는 개역개정 본문 지식으로 대조했다. 수정 뒤 10편 모두 build.js 변환 성공, JSON 유효, 본문 글자 수 8,000자 이상(8,142~8,844자).

## 51 날마다 성경을 상고하는 사람들
- [인용] 왕하 23:25 '마음을 다하며 … 요시야 전에도 이와 같은 왕이 없었고 그 후에도 …' → '요시야와 같이 마음을 다하며 뜻을 다하며 힘을 다하여 모세의 모든 율법을 따라 여호와께로 돌이킨 왕은 요시야 전에도 없었고 후에도 그와 같은 자가 없었더라' (개역개정 대조)
- [인용] 딤후 1:5 '이는 네 속에 있는 거짓이 없는 믿음을 생각함이라' → '이는 네 속에 거짓이 없는 믿음이 있음을 생각함이라' (개역개정 대조)
- [인용] 3대지 해설에서 "'그러므로'라는 연결이 있습니다"라고 했으나 개역개정 12절에는 그 말이 없음 → "원문에는 이 구절 앞에 '그러므로'라는 연결어가 있습니다"로 바로잡음
- [사실] 로이스·유니게가 디모데에게 '날마다' 성경을 가르쳤다는 표현은 성경에 없음 → '어려서부터'(딤후 3:15)로 고침
- 확인 불가(목사님 확인 권장): 없음

## 52 알지 못하는 신에게
- [인용] 벧후 2:7-8: 개역개정의 괄호 부분 '(이는 이 의인이 … 상함이라)'에서 빠진 '이는'과 괄호를 되살림 (개역개정 대조)
- [사실] 파스칼의 '메모리얼'은 가족이 아니라 사후에 하인이 발견했다는 것이 통설이라, 발견자를 빼고 수동형으로 고침. '평생 지니고 다녔다' → '그날 이후 세상을 떠날 때까지 약 팔 년 동안'(1654→1662)
- 확인 불가(목사님 확인 권장): 없음

## 53 두려워하지 말며 침묵하지 말라

- 확인 불가(목사님 확인 권장): 없음

## 54 브리스길라와 아굴라, 그리고 아볼로
- 문제 없음 (인용: 행 18:18·21·24-28, 왕하 4:9-10, 삼상 23:16-17, 잠 9:8, 고전 3:6 모두 개역개정과 일치. 브리스길라 이름이 먼저 나오는 횟수(6회 중 4회), 바빙크의 '신비는 교의학의 생명', 메이첸의 1929년 웨스트민스터 설립 모두 사실과 맞음)

## 55 성령을 받았느냐
- [인용] 행 2:38 '성령의 선물을 받으리니'(개역한글) → '성령을 선물로 받으리니' (개역개정 대조)
- [인용] 엡 4:30 '성령을 근심하게 하지 말라' → '하나님의 성령을 근심하게 하지 말라' (개역개정 대조)
- [신학] 두 번째 축복론을 반박하고, 방언이 나타난 일을 구속사의 이정표로 풀어 규범으로 삼지 않은 점이 적절함. 수정 없음
- 확인 불가(목사님 확인 권장): 없음

## 56 주의 말씀이 힘이 있어 흥왕하니라

- [신학] 워필드의 견해는 "개혁파 안에서도 다양한 의견이 있다"고 이미 균형 있게 다룸. 수정 없음
- 확인 불가(목사님 확인 권장): 없음

## 57 우상의 도시를 흔든 복음
- [사실] 토마스 선교사가 '스물일곱 살'에 순교했다는 것은 한국식 나이이고, 만 나이로는 26세(1839년 9월생, 1866년 9월 순교) → '이십 대 후반의 젊은 나이로'
- [인용] '내가 너희와 함께 있으리라'는 개역개정 문구가 아님 → '볼지어다 내가 세상 끝날까지 너희와 항상 함께 있으리라'(마 28:20)
- [인용] '내가 이 반석 위에 내 교회를 세우리니 …'에 장절(마 16:18)을 덧붙임
- 확인 불가(목사님 확인 권장): 토마스 선교사가 건넨 성경을 벽지로 썼다는 일화는 본문에 이미 "전해지는 이야기", "전승마다 다르다"로 완화되어 있음. 그대로 두었음

## 58 떡을 떼려 하여 모였더니

## 59 하나님의 뜻을 다 너희에게 전하였노라
- [품질/사실] "바울은 이 설교에서 눈물을 세 번 언급합니다"라고 하면서 37절(장로들의 눈물, 누가의 서술)까지 포함함 → "이 고별 장면에는 눈물이 세 번 나옵니다. 바울이 말한 19절·31절의 눈물과 37절 장로들의 눈물"로 고침
- 확인 불가(목사님 확인 권장): 서서평이 반쪽 담요·동전 몇 닢·강냉이 가루를 남겼다는 것과, 루비 켄드릭의 순교 뒤 고향 청년들이 선교사로 자원했다는 이야기는 널리 알려진 전승이며 본문에 "전해집니다"로 완화되어 있음

## 60 자기 피로 사신 하나님의 교회
- [사실] 고멜이 '노예처럼 팔리는 신세가 되었다'는 것은 본문(호 3:2)의 해석이지 성경의 서술이 아님 → '값을 치러야만 되찾을 수 있는 비참한 처지'로 완화
- [사실] 마게도냐 교회들의 연보 대상을 '기근을 겪는 예루살렘 성도들'이라 했으나 고후 8장과 롬 15:26은 '가난한 성도들'로 말함 → '가난한 예루살렘 성도들'
- [인용] 서론의 베드로 인용 풀이에 장절(벧전 1:18-19)을 덧붙임
- 확인 불가(목사님 확인 권장): 박성춘의 회심 과정(에비슨의 치료와 무어 선교사의 곤당골교회)은 대체로 맞지만 세부가 단순화되어 있음
